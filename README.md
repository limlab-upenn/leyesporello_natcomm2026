# leyesporello_natcomm2026
Codes for Leyes Porello et al., 2026.

MATLAB codes draw from the pathnames recorded in the "spacer analysis" spreadsheet. 

The following codes are used

1. two_color_segmentation.m to segment nuclei
2. ms2_signal_auto.m to extract MS2 signals over time for each nucleus
3. Spacers_analysis_code_automated.m to analyze relevant transcription properties.
4. comparing_across_movies_automated_updated.m to plot 

All inputs are from the "spacer analysis.xlsx"
